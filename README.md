# README

## About

This project is a Stellaris Random Empire Generator app, which helps you to create new random empires in Stellaris, as the base game one
usually lacks usabiltiy. Please note, most of this app was vibe-coded and AI built, expect bugs or unvalid outputs.
The whole repository is open-source and feel free to change anything, work on it. You can do pull requests if you want to add it to the original repo.

## Using
If you download the whole repository, you have to go to build\bin to find the .exe that is the whole application, then run it and there you go :)

## Building

To build a redistributable, production mode package, use `wails build`.
